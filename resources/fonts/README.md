# Monaspace

The five unmodified variable WOFF2 families in the renderer assets were downloaded
from the [official Monaspace repository](https://github.com/githubnext/monaspace/tree/main/fonts/Web%20Fonts/Variable%20Web%20Fonts)
on 2026-10-31. CSS registers Neon, Argon, Xenon, Radon and Krypton under their family names.

Monaspace is distributed under the SIL Open Font License. Keep
`Monaspace-LICENSE.txt` with distributions of the app. This resource is included
in the Electron package alongside the bundled font assets.
